# Historical Linear chat experiment

The [original trace](../archive/2026-09-era/research/golden-goose-chat-route.md)
is retained as a dated research record. It does not define the current product
scope or a required inference path.

Inference is configurable through [provider adapters](plan/inference.md),
including a separately verified [T3 Code Connect bridge](plan/t3-code-connect.md).
Linear sign-in uses the public API through [one integration](plan/integrations.md).
The application owns automation execution and persistence.
