# archive/swarm-era

Historical record of the swarm-coordination era (2026-09-26/27): the coordination
protocol (v1 through v4.6), the fleet boot text, rosters, the epoch registry, role
and lead manuals, handoff and claims machinery, and the first `.agents/skills` set.

Archived 2026-09-27 when the user ordered simplification: the machinery produced
identity collisions in every generation that used it, and coordination cost more
than it coordinated. Kept for history only; nothing here is current.

The code of that era is not in this directory. It is preserved at git tag
`archive/v0-swarm-era` (M0-M5, ~26k LOC, tests green), and its open-PR branches
remain on the remote.

Current docs live at the repo root: `README.md`, `AGENTS.md`, `PLAN.md`,
`STATUS.md`.
